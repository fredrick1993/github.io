Building a Gut Microbiome Pipeline
from Raw Sequences to Publication Figure

A full walkthrough of the Python and R pipeline I built for EPP 604 — processing 16S rRNA amplicon data from two polyphagous insect species and visualizing bacterial genus-level community composition on HPC.

Bioinformatics Microbiome Python R SLURM

For my EPP 604 final project, I built a fully reproducible bioinformatic pipeline that takes raw 16S rRNA amplicon sequencing data from the guts of two agricultural caterpillar pests and produces a publication-quality visualization of bacterial community composition. This post walks through the entire project — the biology behind it, every data file involved, the code I wrote step by step, and what the final figure shows.

The Science — Why Insect Gut Microbiomes?

Insect herbivores form symbiotic associations with gut bacteria that can influence nutrition, detoxification of plant compounds, and even how plants respond to being eaten. For polyphagous insects — those that feed on many different plant species — understanding what shapes their gut bacterial communities has real implications for agricultural pest management.

This project uses data from Jones et al. (2019), published in Scientific Reports, which studied two major noctuid pests collected from Pennsylvania farms:

  • Spodoptera frugiperda (fall armyworm) — a highly destructive polyphagous pest devastating corn, soybean, and wheat fields across the Americas and increasingly in Africa.
  • Helicoverpa zea (corn earworm) — another polyphagous pest distributed throughout the Americas, primarily attacking maize but also feeding on tomato, cotton, and soybean.
The central finding: Host plant diet (corn vs. soybean) was a far stronger driver of gut bacterial community composition than the insect's egg population source — whether from a wild field population or a laboratory colony.

The Dataset

The data is publicly available through NCBI SRA under accession number PRJNA507591. Three files make up the entire dataset:

  • seqtab_nochim_polyphagous.txt — The ASV count table. A 56 × 410 matrix of integer read counts. Each column is a unique bacterial DNA sequence (ASV); each row is a sample. Total reads: 719,184. Produced by mothur v.1.37 after chimera removal.
  • tax_assignments_polyphagous.txt — The taxonomy table. Classifies all 410 ASVs across seven taxonomic ranks (Kingdom through Species) using the RDP classifier. This is what turns raw DNA sequences into named bacteria.
  • polyphagous_microbiome_metadata.csv — Sample metadata. 56 rows describing each sample with Run ID, geographic location, host species, and a free-text isolation_source field that combines diet, gut region, egg source, and replicate number.
What is an ASV?
An Amplicon Sequence Variant is an exact unique bacterial DNA sequence — more precise than older OTU methods that cluster sequences at 97% similarity. The 410 column names in the seqtab file are actual 253bp DNA strings that get matched against the taxonomy table to retrieve genus names like Enterococcus or Pseudomonas.

The Pipeline

Three scripts run in sequence. Python processes the raw data and writes a clean CSV. R reads that CSV and produces the final figure. A BASH script submits both to the SLURM cluster at UTK (ISAAC).

Python — parse_microbiome.py

The script accepts four file paths on the command line using Python's built-in sys.argv — no external libraries needed for that part. A safety check at the top exits with a clear usage message if the wrong number of arguments is provided.

Stage 1 — Load files. All three data files are loaded with pandas.read_csv(). The seqtab row names arrive with a file suffix (_filtn.R1.fastq.gz) that must be stripped to match the Run IDs in the metadata — a simple list comprehension handles this.

Stage 2 — parse_metadata(). A user-defined function uses the re module with re.search() and conditional statements inside a for loop to parse the messy isolation_source column and extract three clean fields: insect_species, diet, and sample_type.

Stage 3 — collapse_to_genus(). A second user-defined function transposes the seqtab, joins it with the taxonomy table on the shared ASV sequence index using Pandas, groups by genus, and sums read counts. This collapses 410 ASVs down to 139 genera.

Stage 4 — Normalize. Raw read counts range from 34 to 81,471 per sample and cannot be directly compared. A for loop divides each sample's counts by its total and multiplies by 100. Every single row sums to exactly 100.0%.

Stage 5 — Merge and write. The relative abundance table is merged with the parsed metadata on Run ID. The negative control sample is removed, leaving 55 biological samples. The final dataframe (55 rows × 146 columns) is written to summarized_genus_abundance.csv.

import sys
import pandas as pd
import re

if len(sys.argv) != 5:
    print("Usage: python parse_microbiome.py <seqtab> <taxonomy> <metadata> <output>")
    sys.exit(1)

seqtab_file   = sys.argv[1]
taxonomy_file = sys.argv[2]
metadata_file = sys.argv[3]
output_file   = sys.argv[4]

seqtab   = pd.read_csv(seqtab_file,   sep='\t', index_col=0)
taxonomy = pd.read_csv(taxonomy_file, sep='\t', index_col=0)
metadata = pd.read_csv(metadata_file)

seqtab.index = [i.replace('_filtn.R1.fastq.gz', '') for i in seqtab.index]

def parse_metadata(df):
    species_list, diet_list, stype_list = [], [], []
    for src in df['isolation_source']:
        s = src.lower()
        if 'fall armyworm' in s:   species = 'S. frugiperda'
        elif 'corn earworm' in s:  species = 'H. zea'
        else:                      species = 'Control'
        if re.search(r'soy', s):   diet = 'Soybean'
        elif re.search(r'corn', s): diet = 'Corn'
        else:                      diet = 'Unknown'
        if re.search(r'\bgut\b', s):  stype = 'Midgut'
        elif re.search(r'\breg\b', s): stype = 'Regurgitant'
        else:                         stype = 'Midgut'
        species_list.append(species)
        diet_list.append(diet)
        stype_list.append(stype)
    df['insect_species'] = species_list
    df['diet']           = diet_list
    df['sample_type']    = stype_list
    return df

def collapse_to_genus(seqtab, taxonomy):
    merged = seqtab.T.join(taxonomy[['Genus']], how='left')
    merged['Genus'] = merged['Genus'].fillna('Unclassified')
    return merged.groupby('Genus').sum().T

metadata     = parse_metadata(metadata)
genus_counts = collapse_to_genus(seqtab, taxonomy)

genus_rel = genus_counts.copy().astype(float)
for sample in genus_rel.index:
    total = genus_rel.loc[sample].sum()
    if total > 0:
        genus_rel.loc[sample] = genus_rel.loc[sample] / total * 100

genus_rel['Run'] = genus_rel.index
final_df = metadata.merge(genus_rel, on='Run', how='inner')
final_df = final_df[final_df['insect_species'] != 'Control']
final_df.to_csv(output_file, index=False)

R — plot_microbiome.R

The R script reads three command-line arguments using commandArgs(trailingOnly = TRUE): input CSV, output PDF, and number of top genera. A user-defined function get_top_genera() uses setdiff() to isolate genus columns from metadata columns, ranks them by colSums(), and returns the top N names. With N=10 the result is: Unclassified, Enterococcus, Raoultella, Glutamicibacter, Halomonas, Shewanella, Escherichia-Shigella, Neorhizobium, Bacillus, and Lactococcus — Enterococcus matching the paper's findings exactly.

The data is then filtered to remove unknown-diet samples, a group label is created by combining diet and sample type, the data is reshaped from wide to long format, and sample replicates are averaged within each group. The final stacked bar chart is built with ggplot2 and split into two panels by insect species using facet_wrap().

library(tidyverse)

args <- commandArgs(trailingOnly = TRUE)
if (length(args) != 3) stop("Usage: Rscript plot_microbiome.R <input> <output> <top_n>")

input_file  <- args[1]
output_file <- args[2]
top_n       <- as.integer(args[3])

df <- read.csv(input_file, header = TRUE, sep = ",")

get_top_genera <- function(df, n) {
  meta_cols  <- c("Run","geo_loc_name","HOST","isolation_source",
                  "insect_species","diet","sample_type")
  genus_cols <- setdiff(colnames(df), meta_cols)
  top_genera <- names(sort(colSums(df[genus_cols]), decreasing = TRUE))[1:n]
  return(top_genera)
}

top_genera <- get_top_genera(df, top_n)
meta_cols  <- c("Run","geo_loc_name","HOST","isolation_source",
                "insect_species","diet","sample_type")

plot_df <- df[, c(meta_cols, top_genera)] %>%
  filter(diet != "Unknown") %>%
  mutate(group = paste(diet, sample_type, sep = " - ")) %>%
  pivot_longer(cols = top_genera, names_to = "Genus", values_to = "RelAbund") %>%
  mutate(Genus = gsub("\\.", "-", Genus)) %>%
  group_by(insect_species, group, Genus) %>%
  summarise(RelAbund = mean(RelAbund))

project_plot <- ggplot(plot_df, aes(x = group, y = RelAbund, fill = Genus)) +
  geom_bar(stat = "identity", position = "stack") +
  facet_wrap(~ insect_species, scales = "free_x") +
  labs(title = "Relative Abundance of Top Genera by Group",
       x = "Group (Diet - Sample Type)",
       y = "Relative Abundance (%)") +
  theme_minimal() +
  theme(axis.text.x = element_text(angle = 45, hjust = 1))

ggsave(output_file, plot = project_plot, width = 14, height = 8)

BASH — run_pipeline.sh

Submitted to ISAAC using sbatch. Activates the conda environment, defines all file paths as variables at the top, runs Python first, checks the exit code with $?, and only proceeds to R if Python completed successfully.

#!/bin/bash
#SBATCH --nodes=1
#SBATCH --time=00:30:00
#SBATCH --mem=16GB
#SBATCH -A ACF-UTK0011
#SBATCH --qos=campus
#SBATCH --partition=campus
#SBATCH --ntasks-per-node=1
#SBATCH --job-name=microbiome_pipeline
#SBATCH --output=jobout-toladele.o%j.txt
#SBATCH --chdir=/lustre/isaac24/proj/UTK0438/toladele/PROJECT
#SBATCH --mail-user=toladele@utk.edu
#SBATCH --mail-type=ALL

source ~/.bashrc
conda activate /lustre/isaac24/scratch/toladele/envs/epp604

SEQTAB=seqtab_nochim_polyphagous.txt
TAX=tax_assignments_polyphagous.txt
META=polyphagous_microbiome_metadata.csv
INTER=summarized_genus_abundance.csv
FIGURE=microbiome_barplot.pdf

echo "Running Python..."
python parse_microbiome.py $SEQTAB $TAX $META $INTER

if [ $? -ne 0 ]; then echo "Python failed. Exiting."; exit 1; fi

echo "Running R..."
Rscript plot_microbiome.R $INTER $FIGURE 10
echo "Done. Figure saved: $FIGURE"

Results and Interpretation

The final stacked bar chart shows the top 10 bacterial genera by relative abundance across all sample groups, split into two panels — one for S. frugiperda and one for H. zea. Bars are grouped by diet and gut region. The y-axis correctly runs 0–100% because sample replicates are averaged within groups before plotting.

Key finding confirmed: Enterococcus dominates across multiple fall armyworm groups and shifts visibly between corn-fed and soybean-fed larvae — directly supporting the paper's conclusion that host plant is the primary driver of gut microbiome composition. The corn earworm panel shows a clearly different community from fall armyworm even at the same collection site.

What I Learned

  • sys.argv over argparse — for a fixed-input pipeline, positional sys.argv is cleaner and maps directly to how the BASH script passes arguments.
  • Reshape before you plot — ggplot2 requires long-format data. Understanding why the reshape step is necessary was the key conceptual hurdle in building the R script.
  • Average within groups before stacking — plotting raw per-sample data inflates the y-axis. Group-wise averaging is the correct approach for microbiome composition figures.
  • The biology validates the code — seeing Enterococcus appear as the dominant genus in my output, exactly as reported in the source paper, confirmed the pipeline was working correctly end to end.
