Building a Gut Microbiome Analysis Pipeline
from Raw Sequences to Publication Figure

A step-by-step walkthrough of the Python and R pipeline I built for EPP 604 — processing 16S rRNA amplicon data from two polyphagous insect species and visualizing bacterial genus-level community composition.

Bioinformatics Microbiome Python R SLURM

For my EPP 604 final project, I built a fully reproducible bioinformatic pipeline that takes raw 16S rRNA amplicon sequencing data from the guts of two agricultural caterpillar pests and produces a publication-quality visualization of bacterial community composition. This post walks through the entire project — the science behind it, every file involved, the code I wrote, and what the final figure shows.

The Science — Why Insect Gut Microbiomes?

Insect herbivores form symbiotic associations with gut bacteria that can influence nutrition, detoxification of plant compounds, and even how plants respond to being eaten. For polyphagous insects — those that feed on many different plant species — understanding what shapes their gut bacterial communities has real implications for agricultural pest management.

This project uses data from Jones et al. (2019), a paper published in Scientific Reports that studied two major noctuid pests collected from Pennsylvania farms:

  • Spodoptera frugiperda (fall armyworm) — a highly destructive polyphagous pest devastating corn, soybean, and wheat fields across the Americas and increasingly Africa.
  • Helicoverpa zea (corn earworm) — another polyphagous pest distributed throughout the Americas, primarily attacking maize but also feeding on tomato, cotton, and soybean.
The central finding of the paper: Host plant diet (corn vs. soybean) was a far stronger driver of gut bacterial community composition than the insect's egg population source — whether it came from a wild field population or a laboratory colony.

The researchers used 16S rRNA amplicon sequencing (V4 region, Illumina MiSeq 2×300bp) and processed reads with mothur v.1.37. The resulting dataset is what I built my pipeline around.

What is an ASV?
An Amplicon Sequence Variant is an exact unique bacterial DNA sequence detected in the study — more precise than older OTU methods that cluster sequences at 97% similarity. The 410 column names in the seqtab file are actual 253bp DNA strings like TACGGAGGGTGCAAGCGTTAAT... that get matched to the taxonomy table to retrieve genus names.

The Pipeline — How It All Connects

The pipeline has three scripts that run in sequence. Python processes the raw data and writes a clean CSV. R reads that CSV and produces the final figure. A BASH script submits both to the SLURM HPC cluster at the University of Tennessee (ISAAC).

Py
Stage 1 — Load all three files with sys.argv
The script accepts four file paths typed on the command line using Python's built-in sys.argv. No external libraries needed — sys.argv[1] through sys.argv[4] map directly to the seqtab, taxonomy, metadata, and output file paths.
✓ CLI input via sys.argv
Py
Stage 2 — parse_metadata() — clean the messy isolation_source column
The isolation_source column combines multiple fields in inconsistent free text (e.g. "fall armyworm - field - corn- gut- rep1"). A user-defined function uses the re module with re.search() and conditional statements to extract three clean columns: insect_species, diet, and sample_type.
✓ user-defined function ✓ re module ✓ conditional statements ✓ for loop
Py
Stage 3 — collapse_to_genus() — merge seqtab + taxonomy
A second user-defined function transposes the seqtab, joins it with the taxonomy table on the shared ASV DNA sequence index using Pandas, fills unclassified ASVs, groups by genus, and sums read counts. The result collapses 410 ASVs down to 139 genera.
✓ user-defined function ✓ Pandas module
Py
Stage 4 — Normalize to relative abundance
Raw read counts range from 34 to 81,471 per sample and cannot be directly compared. A for loop divides each sample's genus counts by its total reads and multiplies by 100 — converting every sample to a 0–100% relative abundance scale. Every row sums to exactly 100.0%.
✓ for loop
Py
Stage 5 — Merge metadata and write CSV
The relative abundance table is merged with the parsed metadata on the Run ID column. The negative control sample is removed, leaving 55 biological samples. The final dataframe (55 rows × 146 columns) is written to summarized_genus_abundance.csv for R.
✓ writes output file for R
R
R Stage 1 — Read arguments and load CSV
The R script uses commandArgs(trailingOnly = TRUE) to read three arguments: the input CSV path, output PDF filename, and number of top genera to display. The CSV written by Python is loaded with read.csv().
✓ CLI input via commandArgs
R
R Stage 2 — get_top_genera() — identify most abundant bacteria
A user-defined function uses setdiff() to isolate genus columns, colSums() to rank by total abundance, and sort() to return the names of the top N genera. With N=10: Unclassified, Enterococcus, Raoultella, Glutamicibacter, Halomonas, Shewanella, Escherichia-Shigella, Neorhizobium, Bacillus, Lactococcus.
✓ user-defined function
R
R Stage 3 — Reshape and average by group
The data is filtered to remove unknown-diet samples, reshaped from wide to long format using base R's reshape(), and averaged within each group using tidyverse — so each bar in the final plot represents the mean relative abundance across replicate samples in that group.
R
R Stage 4 — ggplot2 stacked bar chart
A stacked bar chart is built with ggplot2 using geom_bar(stat="identity", position="stack") and split into two panels with facet_wrap(~ insect_species) — one for S. frugiperda and one for H. zea. Saved to PDF with ggsave() at 300 dpi.
✓ figure saved as PDF
SH
BASH / SLURM — run_pipeline.sh
A BASH script submitted to the ISAAC HPC cluster at UTK using sbatch. Activates the conda environment, defines all file paths as variables, runs Python first, checks the exit code ($?), and only runs R if Python succeeded. Configured with 16GB RAM, 30 minutes walltime, campus partition.
✓ SLURM job submission

The Code

parse_microbiome.py

import sys
import pandas as pd
import re

if len(sys.argv) != 5:
    print("Usage: python parse_microbiome.py <seqtab> <taxonomy> <metadata> <output>")
    sys.exit(1)

seqtab_file   = sys.argv[1]
taxonomy_file = sys.argv[2]
metadata_file = sys.argv[3]
output_file   = sys.argv[4]

seqtab   = pd.read_csv(seqtab_file,   sep='\t', index_col=0)
taxonomy = pd.read_csv(taxonomy_file, sep='\t', index_col=0)
metadata = pd.read_csv(metadata_file)

# Clean seqtab row names
seqtab.index = [i.replace('_filtn.R1.fastq.gz', '') for i in seqtab.index]

def parse_metadata(df):
    species_list, diet_list, stype_list = [], [], []
    for src in df['isolation_source']:
        src_lower = src.lower()
        if 'fall armyworm' in src_lower:
            species = 'S. frugiperda'
        elif 'corn earworm' in src_lower:
            species = 'H. zea'
        else:
            species = 'Control'
        if re.search(r'soy', src_lower):
            diet = 'Soybean'
        elif re.search(r'corn', src_lower):
            diet = 'Corn'
        else:
            diet = 'Unknown'
        if re.search(r'\bgut\b', src_lower):
            stype = 'Midgut'
        elif re.search(r'\breg\b', src_lower):
            stype = 'Regurgitant'
        else:
            stype = 'Midgut'
        species_list.append(species)
        diet_list.append(diet)
        stype_list.append(stype)
    df['insect_species'] = species_list
    df['diet']           = diet_list
    df['sample_type']    = stype_list
    return df

def collapse_to_genus(seqtab, taxonomy):
    seqtab_t = seqtab.T
    merged = seqtab_t.join(taxonomy[['Genus']], how='left')
    merged['Genus'] = merged['Genus'].fillna('Unclassified')
    genus_table = merged.groupby('Genus').sum()
    return genus_table.T

metadata     = parse_metadata(metadata)
genus_counts = collapse_to_genus(seqtab, taxonomy)

genus_rel = genus_counts.copy().astype(float)
for sample in genus_rel.index:
    total = genus_rel.loc[sample].sum()
    if total > 0:
        genus_rel.loc[sample] = genus_rel.loc[sample] / total * 100

genus_rel['Run'] = genus_rel.index
final_df = metadata.merge(genus_rel, on='Run', how='inner')
final_df = final_df[final_df['insect_species'] != 'Control']
final_df.to_csv(output_file, index=False)

plot_microbiome.R

library(tidyverse)

args <- commandArgs(trailingOnly = TRUE)
if (length(args) != 3) {
  stop("Usage: Rscript plot_microbiome.R <input_csv> <output_pdf> <top_n>")
}

input_file  <- args[1]
output_file <- args[2]
top_n       <- as.integer(args[3])

df <- read.csv(input_file, header = TRUE, sep = ",")

get_top_genera <- function(df, n) {
  meta_cols  <- c("Run","geo_loc_name","HOST","isolation_source",
                  "insect_species","diet","sample_type")
  genus_cols <- setdiff(colnames(df), meta_cols)
  genus_sums <- colSums(df[genus_cols])
  top_genera <- names(sort(genus_sums, decreasing = TRUE))[1:n]
  return(top_genera)
}

top_genera <- get_top_genera(df, top_n)
meta_cols  <- c("Run","geo_loc_name","HOST","isolation_source",
                "insect_species","diet","sample_type")

sub_df   <- df[, c(meta_cols, top_genera)]
plot_df  <- sub_df %>%
  filter(diet != "Unknown") %>%
  mutate(group = paste(diet, sample_type, sep = " - ")) %>%
  pivot_longer(cols = top_genera, names_to = "Genus", values_to = "RelAbund") %>%
  mutate(Genus = gsub("\\.", "-", Genus)) %>%
  group_by(insect_species, group, Genus) %>%
  summarise(RelAbund = mean(RelAbund))

project_plot <- ggplot(plot_df, aes(x = group, y = RelAbund, fill = Genus)) +
  geom_bar(stat = "identity", position = "stack") +
  facet_wrap(~ insect_species, scales = "free_x") +
  labs(title = "Relative Abundance of Top Genera by Group",
       x = "Group (Diet - Sample Type)",
       y = "Relative Abundance (%)") +
  theme_minimal() +
  theme(axis.text.x = element_text(angle = 45, hjust = 1))

ggsave(output_file, plot = project_plot, width = 14, height = 8)

run_pipeline.sh

#SBATCH --nodes=1
#SBATCH --time=00:30:00
#SBATCH --mem=16GB
#SBATCH -A ACF-UTK0011
#SBATCH --qos=campus
#SBATCH --partition=campus
#SBATCH --ntasks-per-node=1
#SBATCH --job-name=microbiome_pipeline
#SBATCH --output=jobout-toladele.o%j.txt
#SBATCH --chdir=/lustre/isaac24/proj/UTK0438/toladele/PROJECT
#SBATCH --mail-user=toladele@utk.edu
#SBATCH --mail-type=ALL

source ~/.bashrc
conda activate /lustre/isaac24/scratch/toladele/envs/epp604

SEQTAB=seqtab_nochim_polyphagous.txt
TAX=tax_assignments_polyphagous.txt
META=polyphagous_microbiome_metadata.csv
INTER=summarized_genus_abundance.csv
FIGURE=microbiome_barplot.pdf
TOP_N=10

echo "Running Python..."
python parse_microbiome.py $SEQTAB $TAX $META $INTER

if [ $? -ne 0 ]; then
    echo "Python failed. Exiting."
    exit 1
fi

echo "Running R..."
Rscript plot_microbiome.R $INTER $FIGURE $TOP_N
echo "Pipeline complete. Figure: $FIGURE"

Results and Interpretation

The final stacked bar chart shows the top 10 bacterial genera by relative abundance, split into two panels — one for S. frugiperda (fall armyworm) and one for H. zea (corn earworm) — with bars grouped by diet and gut region.

Key Visual Findings
Enterococcus (pink) dominates across multiple fall armyworm groups, consistent with the paper's finding that it is one of the most abundant taxa. The composition clearly shifts between corn-fed and soybean-fed larvae, supporting Jones et al.'s conclusion that host plant is the primary driver of gut microbiome composition. The corn earworm panel shows a notably different community from fall armyworm despite being collected from the same host plant at the same site, reflecting species-specific gut physiology.

The y-axis correctly runs from 0 to 100% because I averaged relative abundances across replicate samples within each group before plotting — ensuring that stacked bars represent true community composition rather than cumulative read counts across individuals.

What I Learned

  • sys.argv over argparse — for a straightforward pipeline with a fixed number of inputs, sys.argv is cleaner and easier to reason about than argparse. The positional approach maps directly to how the BASH script calls the programs.
  • Reshape before you plot — ggplot2 requires long-format data. Understanding why the reshape step is necessary (one row per observation, not one row per sample) was the key conceptual step in building the R script.
  • Average within groups before stacking — plotting raw per-sample data in a stacked bar inflates the y-axis. Group-wise averaging is the correct approach for microbiome composition figures.
  • The biology matches the code — seeing Enterococcus appear as the dominant genus in the output, exactly as reported in the source paper, was a satisfying confirmation that the pipeline was working correctly.
